# Dinesh Kumara
`Portfolio`

Personal portfolio website, built to showcase projects, skills, and professional experience.

GitHub: [Dinesh-N98](https://github.com/Dinesh-N98)

## Tech Stack

- React
- Vite
- Tailwind CSS
- Vercel

## Local Development

```bash
npm install
npm run dev
```

The development server will print the local URL in the terminal.
